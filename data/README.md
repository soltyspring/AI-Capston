# 요청 데이터

`demo.jsonl`은 직접 만든 8개 합성 요청입니다. Mooncake 원본이 아닙니다.

실험 데이터: [Mooncake FAST25 안내](https://github.com/kvcache-ai/Mooncake/blob/main/FAST25-release/README.md)

공식 `FAST25-release/traces/conversation_trace.jsonl`을 내려받아 사용합니다.

| 필드 | 의미 |
|---|---|
| timestamp | 상대 도착 시각, 밀리초 |
| input_length | 입력 토큰 수 |
| output_length | 완료 후 확인하는 실제 출력 토큰 수 |
| hash_ids | 공통 입력 비교용 블록 식별자 배열, 블록당 512토큰 |

JSONL 형식으로 한 줄에 요청 하나입니다. 실제 질문·답변·GPU 사용률·서버 배정·큐·KV 텐서는 없습니다.
hash_ids는 토큰 ID가 아닙니다. 서버 상태는 시뮬레이터가 계산합니다.

전처리: 필드 타입/범위, 블록 수, 시간순 정렬 여부를 검증하고 ms를 초로 변환합니다.
같은 시각의 요청도 보존합니다. 초과 입력은 자르지 않고 거절 통계에 포함합니다.
처리 가능 여부는 입력 + 설정 출력 한도(2048)로 판단합니다. 미래 실제 출력은 사용하지 않습니다.

시간순 앞 70%로 입력 길이 구간별 평균 출력 길이를 학습하고 뒤 15%를 평가합니다.
중간 15%는 향후 튜닝용으로 남깁니다. 두 정책의 캐시는 모두 빈 상태로 시작합니다.
이는 지도학습 기준선이며 자기지도학습이나 강화학습이 아닙니다.
