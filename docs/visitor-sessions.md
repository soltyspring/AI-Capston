# 방문자별 시뮬레이션과 동적 설명

## 상태 분리

- `aicap_session`: 서버가 발급하는 256비트 난수 식별자. HttpOnly·SameSite=Lax, HTTPS에서 Secure 쿠키로 전달합니다. 응답은 `private, no-store`이며 세션 식별자는 JSON에 노출하지 않습니다.
- 방문자마다 Simulator, 가상 서버 3대, 큐, KV 캐시, 시각, 정책, 속도, 실행 여부, 초기화 횟수를 별도로 보관합니다. 모델과 원본 요청 기록만 공유합니다.
- 같은 브라우저 프로필의 탭은 쿠키를 공유하므로 같은 방문자로 취급합니다. 다른 브라우저·시크릿 창·다른 방문자는 독립적입니다.
- 마지막 API 요청 이후 30분이면 만료됩니다. 열린 화면은 0.5초 간격으로 조회하므로 세션이 유지됩니다. 서버 재시작 시 초기화됩니다. 영구 저장이나 로그인 기반 소유권 기능은 아닙니다.
- 최대 48개 세션을 유지하며 가득 차면 새 방문자에게 503을 반환합니다. 기존 방문자를 강제로 퇴출하지 않습니다. 1분마다 만료 세션을 정리하고 API 요청에서도 정리합니다.
- 단일 Uvicorn 워커에서 동작합니다. 여러 워커/서버를 사용하려면 Redis 등 공유 세션 저장소와 방문자별 동기화가 필요합니다.

## 시간 진행

전역 재생 타이머를 제거했습니다. 각 방문자가 API를 호출할 때 monotonic clock으로 자기 세션의 경과 시간 × 배속만큼 진행합니다. 일시정지·속도 변경 직전까지 기존 속도로 진행하고 이후 설정을 적용합니다. 접속하지 않은 세션을 매 틱 계산하지 않습니다. 30분 이내 다시 접속하면 경과분을 반영합니다.

## 동적 안내

1. 사용자 입력: 타이핑 예시와 입력 요청의 역할 설명. 예시 문장은 창작된 설명용이며 Mooncake 원문이 아닙니다. 실제 자유 입력·LLM 추론 API는 추가하지 않았습니다.
2. 비용 비교: 대기 + 입력 처리 + 예측 답변 생성, 현재 동등 가중치 1:1:1. 실제로 새로운 가중치 설정·학습 기능을 추가하지 않았습니다. 캐시를 입력 처리에 반영하고 토큰 용량 조건을 검사합니다.
3. 분배: 최신 결정의 선택 서버와 비용 항목을 표시합니다. Round Robin에서는 순번 정책이 적용된다는 점도 명시합니다.
4. 결과·학습: 실제 완료 기록의 예측/실제 토큰과 오차를 표시합니다. 현재는 과거 기록을 사용한 지도학습 모델이며, 재생 중 온라인 학습/강화학습이 수행되는 것처럼 표시하지 않습니다. 강화학습은 향후 계획입니다.

설명은 6.5초마다 단계가 전환되며 수동 단계 선택/자동 재생 해제를 지원합니다. 동작 줄이기를 선호하는 브라우저에서는 자동 재생과 타이핑을 기본 비활성화합니다. 설명 애니메이션과 실제 데이터 재생은 별도입니다. 큰 화면에서는 노드 옆 말풍선, 좁은 화면에서는 선택한 단계의 카드로 표시합니다.
